# ClassicSpeech 1.03

ClassicSpeech 1.03 adds Josh Kennedy to the add-on's author credits, next to the original authors, Tim and Calli. Speech and settings are unchanged from 1.02.

Supported NVDA versions: 2025.1 through 2026.2.

## Changes

The add-on's author line now reads:

> Tim and Calli (https://github.com/trssharp/classicspeech-nvda), Josh Kennedy (https://github.com/joshknnd1982)

NVDA shows it as **Author** in the Add-on Store's details for ClassicSpeech, on the **Installed add-ons** tab.

## Also in this release

Everything from [ClassicSpeech 1.02](https://github.com/joshknnd1982/classicspeech-nvda/releases/tag/v1.02):

* faster speech in Windows Explorer and file dialogs;
* edit field contents read on focus, with a Verbosity option to turn it off;
* address bar and similar fields keep their name;
* a Mouse voice profile;
* document and web formatting voices;
* Speech and Sound Schemes.

## Installation

1. Download `ClassicSpeech-1.03.nvda-addon`.
2. Open it from Windows Explorer and accept NVDA's installation prompt. It replaces ClassicSpeech 1.02.
3. Restart NVDA when prompted.

## Verification

* Full local harness gate and the GitHub Actions workflow, which also built this package.
* The packaged manifest passes NVDA 2026.2's add-on manifest validation, with version 1.03 and the new author line.
* Live NVDA testing of the 1.02 changes has not been done yet. The checklist in the [1.02 release notes](https://github.com/joshknnd1982/classicspeech-nvda/releases/tag/v1.02) still applies.
